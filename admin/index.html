Měníte heslo nebo GitHub token? Nastavit znovu

Nastavení hesla

  1. Na GitHubu otevřete Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → . Permissions → Repository → Contents: Read and write. Platnost klidně 1 rok.
  3. Token vložte sem a zvolte heslo pro administraci. Token se heslem zašifruje a uloží do repozitáře jako admin/key.json. Bez hesla je k ničemu.
Aspoň 14 znaků. Nejlépe 4–5 náhodných slov, např. brankář-lavička-penalta-otava.
